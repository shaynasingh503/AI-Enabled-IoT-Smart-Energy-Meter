# ACS712 Current Sensor

## Overview

The ACS712 is a Hall-effect current-sensor module. Current flowing through the monitored load path produces an analog output that can be measured by the ESP32.

## Role in this project

- Measures current drawn by the connected load
- Supplies the current value shown on the LCD, Serial Monitor, and Blynk dashboard
- Works with the voltage measurement to estimate power

## Connection to ESP32

| ACS712 pin | ESP32 connection | Purpose |
| --- | --- | --- |
| VCC | 3.3 V | Module supply |
| GND | GND | Common low-voltage reference |
| OUT | GPIO 34 | Analog current-sensor output |

The current path is connected in series with the monitored load according to the specific ACS712 module markings.

## Software use

The firmware calibrates the sensor midpoint at startup and averages multiple samples to reduce noise.

```cpp
ACS712 ACS(34, 3.3, 4095, 125);
ACS.autoMidPoint();
```

## Calibration and safety

Test the reading with known loads and compare it to a trusted current or power meter. Select a suitable ACS712 range for the expected load, and ensure the mains wiring is insulated and enclosed.
